FastAPI backend for TrustTable. Repository-foundation stage (`FND-01`):
only the operational endpoints exist (`/api/v1/health/live`,
`/api/v1/health/ready`, `/api/v1/version`). No product features yet.

See `../docs/local-development.md` for local run instructions (native and
Docker) and `../CONTRIBUTING.md` for project working rules.
